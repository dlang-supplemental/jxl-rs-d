= jxl-rs-d

D bindings for link:https://github.com/libjxl/jxl-rs[jxl-rs], the memory-safe Rust JPEG XL *decoder* used by Chromium and Firefox.

link:https://dlang-supplemental.github.io/jxl-rs-d/[Explore the docs] ·
link:https://github.com/dlang-supplemental/jxl-rs-d/issues[Report Bug]
endif::[]

Install: `dub add jxl-rs-d`

Encode is intentionally out of scope. For encode + a unified D API, see https://github.com/dlang-supplemental/jxl-d[`jxl-d`] (libjxl encode + this package for decode).

== Requirements

* D compiler (`ldc2` or `dmd`) and link:https://dub.pm/[dub]
* link:https://rustup.rs/[Rust]/ + Cargo (edition 2024 capable; rustc 1.85+)
* Network on first `cargo build` to fetch crates.io deps

== Usage

[source,d]
----
import jxl_rs;

void main()
{
    auto img = decodeRgba8(cast(immutable(ubyte)[]) std.file.read("photo.jxl"));
    // img.width, img.height, img.pixels (RGBA8, tightly packed)
}
----

Build / test:

[source,bash]
----
dub test
----

The `preBuildCommands` in `dub.sdl` compile `jxl_rs_bridge` (Rust `cdylib` / `staticlib`) before the D sources.

=== Layout

* `jxl_rs_bridge/` — C ABI wrapper around the `jxl` crate
* `source/jxl_rs/` — D `extern(C)` bindings + high-level helpers
